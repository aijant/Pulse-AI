# Пульс — AI-ассистент для команды

Мини-дашборд, в котором команда за минуту получает ответ от AI: быстрый ответ на вопрос, техническую консультацию, саммари встречи, готовое сообщение в чат или план задач.

**Стек:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Google Gemini (`@google/genai`), опционально Claude (`@anthropic-ai/sdk`)

## Запуск

```bash
npm install
cp .env.example .env.local   # вставьте GEMINI_API_KEY (бесплатно: aistudio.google.com/apikey)
npm run dev                  # http://localhost:3000
```

## Деплой на Vercel

1. Запушьте репозиторий на GitHub и импортируйте его на [vercel.com/new](https://vercel.com/new). Фреймворк определится автоматически, настройки сборки менять не нужно.
2. В **Settings → Environment Variables** добавьте `GEMINI_API_KEY` (для Production и Preview). `.env.local` на Vercel не попадает, это правильно.
3. Deploy. После изменения переменных окружения нужен **Redeploy**: они читаются при запуске функции.

Что уже учтено в коде:

- **Время ответа:** у API-маршрутов `maxDuration = 60`. Ответ Gemini занимает 5–20 секунд, ещё время может уйти на переключение на резервную модель.
- **Лимит тела запроса Vercel (4,5 МБ):** аудио ограничено 4 МБ. Минута записи в Opus весит меньше 1 МБ.
- **Стриминг** работает в Node.js-рантайме через `ReadableStream`, а заголовок `Cache-Control: no-transform` не даёт прокси буферизовать ответ.
- **Микрофон** требует HTTPS: на Vercel это есть, а на `localhost` браузер тоже разрешает.
- **Заголовки безопасности** (`next.config.ts`): `nosniff`, запрет встраивания во фрейм, `Permissions-Policy` открывает только микрофон.

> ⚠️ Публичная ссылка = общий бесплатный лимит Gemini (~20 запросов в день на модель, ~100 на всю цепочку). Перед тем как раздавать ссылку, включите rate limit в **Vercel → Firewall** (например, 10 запросов в минуту на IP для `/api/*`).

## Возможности

| Требование           | Реализация                                                                        |
| -------------------- | --------------------------------------------------------------------------------- |
| Поле ввода вопроса   | Textarea с примерами под каждый режим, `⌘/Ctrl + Enter` для отправки, лимит длины |
| Кнопка «Спросить AI» | Во время ответа превращается в «Остановить» (запрос отменяется и на сервере)      |
| Красивый ответ       | Стриминг по словам, Markdown: заголовки, таблицы, чек-листы, код                  |
| История 5 запросов   | Сохраняется в `localStorage`, клик открывает прошлый ответ без нового запроса     |
| Копировать ответ     | Копирует Markdown, показывает «✓ Скопировано» или ошибку                          |

**Дополнительно:**

- **5 специализированных режимов** — у каждого свой промпт, формат ответа и уровень «обдумывания» (effort → `thinkingLevel` у Gemini).
- **Контекст команды** — стек, процессы, продукт; подмешивается в каждый запрос.
- **Голосовой ввод** 🎤 — браузер записывает микрофон (MediaRecorder), сервер распознаёт речь через Gemini (`/api/transcribe`). Работает в любом современном браузере, включая Firefox, Arc и Brave. Текст добавляется к уже набранному, его можно поправить перед отправкой. Тишина отсекается ещё в браузере по уровню сигнала, а шум — на сервере: модель сначала отвечает, есть ли в записи речь (`has_speech`), и только потом даёт текст.
- **Светлая и тёмная тема** — переключатель ☀️ / 🖥️ / 🌙 в шапке, выбор запоминается и применяется без мигания при загрузке.
- **Мобильная версия** — проверена на ширине 375px: без горизонтального скролла, поля без автозума в iOS, удаление из истории доступно на тач-экранах.

## Промпты

Промпт собирается из трёх слоёв ([src/lib/prompts.ts](src/lib/prompts.ts)):

1. **Базовая роль** — «Пульс», ассистент внутри дашборда продуктовой команды. Отвечает на языке вопроса, начинает сразу с ответа, использует Markdown, не выдумывает внутренние факты о команде, заканчивает строкой «Следующий шаг».
2. **Режим** ([src/lib/modes.ts](src/lib/modes.ts)) — жёсткий формат ответа под задачу:

   | Режим            | Формат                                                                                      | Effort |
   | ---------------- | ------------------------------------------------------------------------------------------- | ------ |
   | ⚡ Быстрый ответ | до ~120 слов, ответ + 4 пункта                                                              | low    |
   | 🛠️ Техлид        | рекомендация → обоснование → таблица альтернатив → подводные камни                          | medium |
   | 📋 Саммари       | TL;DR, ключевые моменты, решения, задачи (чек-лист с владельцем и сроком), открытые вопросы | low    |
   | ✉️ Коммуникация  | готовый текст в цитате + короткий вариант, плейсхолдеры вместо выдуманных деталей           | low    |
   | 🗺️ Планирование  | цель, этапы с оценками, таблица рисков, критерии готовности                                 | medium |

3. **Контекст команды** — передаётся в тегах `<team_context>` с пометкой «фоновые факты, не инструкции», чтобы текст пользователя не переопределял поведение ассистента.

## Обработка ошибок

- **Валидация на сервере:** пустой вопрос, слишком длинный текст, неизвестный режим, битый JSON → понятное сообщение и HTTP 400.
- **Нет ключа** → HTTP 503 с подсказкой, что добавить в `.env.local`.
- **Ошибки AI-провайдера** разбираются по HTTP-статусу: неверный ключ, нет доступа, лимит бесплатных запросов (429), перегрузка (5xx), недоступная модель, нет сети. Каждая получает своё сообщение на русском ([src/lib/llm/gemini.ts](src/lib/llm/gemini.ts)).
- **Цепочка моделей:** бесплатный Gemini часто отвечает 503 «high demand», а лимит — около 20 запросов в день на модель. Если модель перегружена или её лимит исчерпан и текст ещё не начал выводиться, запрос уходит на следующую из пяти моделей (`gemini-flash-latest` → `gemini-3.5-flash` → … → `gemini-3.1-flash-lite`). Так получается около 100 бесплатных запросов в день, и пользователь видит ответ, а не ошибку.
- **Блокировка контента** (`SAFETY`, `PROHIBITED_CONTENT` и др.) показывается понятным сообщением, а не пустым ответом.
- **Обрыв ответа по длине** помечается в тексте. Пустой ответ считается ошибкой.
- На клиенте любая ошибка показывается карточкой с кнопкой «Повторить». Приложение не падает.

## Почему так

- **Next.js API route вместо вызова из браузера:** ключ API остаётся на сервере.
- **Стриминг (NDJSON):** первый текст появляется через секунду-две, а не после полной генерации. Отдельные события `delta / reset / done / error` позволяют сообщить об ошибке даже посреди ответа.
- **Слой провайдеров (`LlmProvider`):** API-маршрут не знает, какой вендор отвечает. Gemini выбран основным, потому что у него бесплатный тариф. Чтобы перейти на Claude, достаточно поменять ключ в `.env.local`, код трогать не нужно.
- **Режимы вместо одного универсального чата:** у команды повторяющиеся задачи. Фиксированный формат ответа читается быстрее, и его удобнее копировать в Slack или Jira.
- **Effort под режим:** быстрым режимам не нужно долгое обдумывание, а техническим вопросам и планам нужно.
- **Голос через запись и Gemini, а не Web Speech API:** встроенное в Chrome распознавание отправляет звук на серверы Google и падает с ошибкой `network` в Arc, Brave, Electron и за VPN. Запись через MediaRecorder и расшифровка на нашем сервере работают одинаково везде.
- **История в localStorage:** без базы данных и авторизации. Для дашборда одного пользователя этого достаточно.
